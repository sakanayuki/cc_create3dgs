# PhotoSplat — 単一写真からブラウザ内で軽量3DGSを生成するWebアプリ

設計書インデックス（**v2 — 品質レビュー改訂版**）

## この文書群について

スマートフォンのブラウザだけで、1枚の写真から3D Gaussian Splatting (3DGS) を生成・閲覧・書き出しするWebアプリの設計書です。
生成処理はすべて端末内で完結し、写真は一切外部に送信されません。ホスティングは GitHub Actions 経由の GitHub Pages のみを使います。

v1 は速度を軸に書かれました。v2 では「スマホでより品質の高い3DGS」を目標にレビューを行い、
**深度の形状精度・遮蔽部の補完・解像度**の3点を中心に設計を見直しています。変更点の一覧は [01 §1.9](./01-requirements.md#19-改訂履歴v1--v2) を参照。

## 30秒サマリ

**やること**: 写真1枚 → 単眼深度推定 → 前面シェル + 背面シェル + スカート → 遮蔽部をインペイント → ガウシアン化 → 量子化 → 表示・書き出し。

**軽量化の核心**: 単一画像由来の3DGSは、ガウシアンが元から2Dピクセル格子上に並んでいる。
そのため一般の3DGS圧縮が数秒かけて行う「属性の2D並べ替え」(KISS-GS の PLAS 等) が**構造的に不要**になり、
`深度 + 色 + α + 背面色 + 補完テクスチャ` の画像として保存するだけで、ソートコストゼロのまま vanilla PLY 比 **約350倍**の削減が得られる。

**品質の核心（v2）**: 形状は深度モデルの選定（Depth Anything 3 Small を第一候補）と深度のエッジ保存シャープ化で、
斜めからの見え方は MI-GAN による遮蔽部インペイントで決まる。色プレーンは写真そのものなので **1024²** で保持する。

**性能目標**: 中位スマホで生成10秒以内、うち約4.9秒で操作可能なプレビューを表示。出力 約750KB（標準）。
