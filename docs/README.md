# PhotoSplat — 単一写真からブラウザ内で軽量3DGSを生成するWebアプリ

設計書インデックス

## この文書群について

スマートフォンのブラウザだけで、1枚の写真から3D Gaussian Splatting (3DGS) を生成・閲覧・書き出しするWebアプリの設計書です。
生成処理はすべて端末内で完結し、写真は一切外部に送信されません。ホスティングは GitHub Actions 経由の GitHub Pages のみを使います。

## 30秒サマリ

**やること**: 写真1枚 → 単眼深度推定 → 前面シェル + 背面シェル + スカート → ガウシアン化 → 量子化 → 表示・書き出し。

**軽量化の核心**: 単一画像由来の3DGSは、ガウシアンが元から2Dピクセル格子上に並んでいる。
そのため一般の3DGS圧縮が数秒かけて行う「属性の2D並べ替え」(KISS-GS の PLAS 等) が**構造的に不要**になり、
`深度16bit + 色RGB + α8bit` の画像として保存するだけで、ソートコストゼロのまま vanilla PLY 比 **約150倍**の削減が得られる。

**性能目標**: 中位スマホで生成10秒以内、うち約4.6秒で操作可能なプレビューを表示。出力 500KB 以下。
