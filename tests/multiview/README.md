# 複数枚モードの実素材

`docs/12-multiview.md` の PoC-3A〜3C と、検査 M1〜M9 で使う写真を置く。

## 置くファイル

| ファイル | 中身 | 必須 |
|---|---|---|
| `front.jpg` | 正面 | 2枚モード・3枚モードとも必要 |
| `right.jpg` | **画面の右**を向いた横向き | 3枚モードで必要 |
| `left.jpg` | **画面の左**を向いた横向き | 3枚モードで必要 |

「右向き／左向き」は**写真の中で被写体がどちらを向いているか**で呼ぶ
（docs/12 §12.2）。撮った人が見たままの呼び方で、UI の枠の名前とも一致する。

## 素材に求めること

同一人物・同じ服・同じ場所・**同じ姿勢**であること。姿勢のうち特に腕は、
3枚で違うと位置合わせが説明できない差になる（docs/12 §12.14 R13）。
違っていても壊れはしない（腕は正面のものだけを使う、D33）が、
横から見たときに腕が消える。

背景は除去するので写り込みは問われない。ただし被写体と背景の色が近いと
マットが難しくなるので、その組み合わせは**検査として価値がある**素材になる。

## 注意

実在の人物の写真である。追加するかどうか、どの写真にするかの判断は
リポジトリの持ち主のものとする。ここにあるのは置き場所と名前の取り決めだけで、
CI はファイルが無ければ該当のテストをスキップする（`test29.jpeg` などと同じ扱い）。
