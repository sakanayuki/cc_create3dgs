# 較正データ

CI（`scripts/calibrate.py`）が量子化前後の精度を測るために使う画像を置く。

## 必要なもの

設計（docs/07 §7.3）が求めるのは **人物6枚・物体6枚の計12枚**。多様な照明・背景・被写体サイズを含めること。
1枚あたり 100KB 程度に圧縮し、リポジトリに直接コミットしてよい（合計 1.2MB 程度）。

## 現状 — 差し替えが必要

いま入っているのは `generate_placeholders.py` が作った**手続き的な合成画像**であり、
パイプラインが通ることを確かめるためだけのもの。**量子化精度の判断材料としては使えない。**

実写に差し替えるまで、`calibrate.py` の数値は「配管が動いている」以上の意味を持たない。

## 差し替え時の注意

- 権利が明確な画像のみ（自前撮影、または CC0 / パブリックドメイン）
- 出所とライセンスを `SOURCES.md` に記録する
- 顔が写る画像は、被写体本人の同意が取れているものに限る
- ファイル名は `person-01.jpg` … `object-06.jpg` の形式に揃える
